# A small slug function

Implement `slug.py` with `slug(text: str) -> str`.
Strip leading/trailing whitespace, lowercase, and replace each run of whitespace with one hyphen.
Preserve all other characters, including punctuation and existing hyphens. Empty or whitespace-only input returns an empty string.

Only create or modify `slug.py`. No packages, CLI, README, or other features are needed.
The fixed validation is `python3 check.py`; do not change `check.py` or this brief.
