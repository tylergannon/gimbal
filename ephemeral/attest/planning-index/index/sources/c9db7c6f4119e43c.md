# security/sessions.md

Purpose: Authenticated session activity policy: inactive sessions expire after exactly 42 minutes; successful authenticated requests refresh activity, while failed authentication attempts do not.

## Themes
- session expiry
- authentication activity refresh
- failed-authentication handling
- exact timeout enforcement

## Citations
- `security/sessions.md:1-3` — Defines the session lifetime and activity-refresh rules.

## Gotchas
- Use exactly 42 minutes, not an approximate or configurable default.
- Only successful authenticated requests refresh activity time.
- Failed authentication must not extend session lifetime.

## Recipes
- Expire a session when its inactivity duration reaches 42 minutes.
- On each successful authenticated request, update the session activity timestamp.
- Leave the activity timestamp unchanged after failed authentication.
