# engineering/text-policy.md

Purpose: Text normalization policy: preserve Unicode in display labels; generate machine slugs by lowercasing, hyphenating whitespace runs, trimming boundary whitespace, and preserving punctuation.

## Themes
- Preserve Unicode for user-facing display labels.
- Normalize machine slugs by lowercasing, trimming boundary whitespace, and converting each whitespace run to one hyphen.
- Keep existing punctuation unchanged during slug generation.

## Citations
- `engineering/text-policy.md:1-3` — Defines display-label and machine-slug normalization behavior.

## Gotchas
- Do not ASCII-fold or remove Unicode from display labels.
- Whitespace normalization applies to machine slugs, not display labels.
- Punctuation is preserved; do not strip, replace, or otherwise normalize existing punctuation.

## Recipes
- For a display label, retain the original Unicode text.
- For a machine slug: lowercase the input, strip boundary whitespace, replace each run of whitespace with a single hyphen, and leave punctuation intact.
