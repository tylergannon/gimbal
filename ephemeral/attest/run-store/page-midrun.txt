Assistant completed **Token caching** (often implemented as prompt or KV caching) is an optimization technique in Large Language Models that stores precomputed internal representations—specifically key-value (KV) attention states—for reused prompt segments. Normally, an LLM recomputes attention across the entire context window for every request, which is computationally expensive and slow for long, repetitive prompts (such as system instructions, few-shot examples, large codebases, or chat history). With token caching, the model saves the computed states of static prefix tokens in memory after the initial pass. On subsequent requests sharing that exact prefix, the system bypasses recomputing those tokens and reads them directly from the cache.
