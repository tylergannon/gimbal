Usage of gimble run-prompt:
  -effort string
    	reasoning effort: low, medium, high, xhigh, or max
  -logs string
    	new project log directory; default is a temporary directory
  -model string
    	model name or alias; omitted inside Codex or Claude selects the opposite provider
  -model-version string
    	exact model-family version
  -output-schema string
    	exact JSON Schema for structured output; omit for plain text
  -timeout duration
    	turn timeout (default 20m0s)
  -workdir string
    	agent workspace (default ".")
