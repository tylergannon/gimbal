# Continue saved conversations after server restart

The conversation prototype in #287 preserves transcripts, provider/model selection, and the associated Git worktree and branch across server restarts. Saved conversations are currently read-only because their native provider session belongs to the previous runtime.

Allow a person to continue a saved conversation after restarting Gimble, preserving the conversation's worktree/branch and prior context. Support the accepted harnesses through their available session-resume mechanisms, or clearly explain when a harness cannot resume. Avoid silently presenting a fresh context as the old native session.

This is deferred from the requested 85% prototype; it does not block #287. Multi-project support and agent-follow navigation remain separate future work.

Source: https://github.com/tylergannon/gimble/issues/288
