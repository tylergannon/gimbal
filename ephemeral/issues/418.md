# Temporal consumer generator accepts discarded Generate results and emits unbuildable Go

## Defect

The consumer-owned Temporal generator accepts a bare `Session.Generate[T]` expression statement that deliberately discards its result and error, reports successful generation, and emits Go that does not build. The authored Go package itself builds.

Reproduced against published Gimbal revision `c50badbc72c071d33f2d9e88dd54c6f8df478da6` (`v0.12.2-0.20260929215251-c50badbc72c0`) in a copied consumer module with no local replacement.

## Reproduction

Copy `examples/temporal` to a separate directory. In that module:

```sh
go mod edit -dropreplace=github.com/tylergannon/gimbal
go get github.com/tylergannon/gimbal@c50badbc72c071d33f2d9e88dd54c6f8df478da6
```

Replace `authored/workflow.go` with this source (the example's Generate assignment, error check, and summary write are removed; the later Scope assignment becomes a declaration):

```go
// Package authored holds the ordinary Go source owned by this consumer.
package authored

import (
	"context"

	"github.com/tylergannon/gimbal"
)

// Delivery records an agent response, then checks a local deliverable.
func Delivery(ctx context.Context, env gimbal.Env) error {
	gimbal.Set(ctx, "assignment", "Create a small, checked delivery.")
	worker := gimbal.NewSession(ctx, "coder", env.WorkDir)
	worker.Generate[gimbal.Text](ctx, "Reply with exactly one sentence describing a small deliverable ready for verification. Only provide the sentence: do not run commands, read or write files, invoke tools, start workflows, or delegate work. The caller creates and checks the deliverable after your reply.")
	err := gimbal.Scope(ctx, "verify", func(ctx context.Context) error {
		err := gimbal.Check(ctx, "delivery", env.WorkDir, "sh", "-c", "printf 'done\n' > delivery.txt && test -s delivery.txt")
		return err
	})
	return err
}

```

Run:

```sh
go test ./authored
go generate ./...
go build .
```

Observed: the first two commands succeed. The generated consumer build fails:

```text
# example.com/temporal-consumer
./delivery_temporal_gen.go:80:2: declared and not used: v7
./delivery_temporal_gen.go:80:6: declared and not used: v8
```

No provider or Temporal server is needed to reproduce this generation/build defect.

## Cause and scope

The [Generate lowering](https://github.com/tylergannon/gimbal/blob/c50badbc72c071d33f2d9e88dd54c6f8df478da6/examples/temporal/internal/temporalgen/generate.go#L641-L645) declares typed value/error locals unconditionally. For an expression statement, [bind(nil, ...)](https://github.com/tylergannon/gimbal/blob/c50badbc72c071d33f2d9e88dd54c6f8df478da6/examples/temporal/internal/temporalgen/generate.go#L545-L547) emits no uses of those locals.

The README recommends explicit result/error assignments. This input is beyond that recommended style, but the generator accepts it instead of issuing a source-located diagnostic. Existing assigned-result examples and the demonstrated real product delivery are unaffected. This belongs in the consumer emitter; it does not require changing Gimbal's shared agent operation or broadening the compiler's language surface.

## Acceptance

A bare Generate statement must either be rejected during generation with a source-located diagnostic and the existing stale-output invalidation behavior, or lower to buildable code that preserves deliberate discard semantics. A focused regression should verify that valid authored Go cannot receive successful generation followed by these unused-local build errors. Existing assigned-result generation must continue to work.

The smallest remedy is a source-located rejection.
