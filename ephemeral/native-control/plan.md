feasibility gate on November 1, 2026. A granted the native-runtime window, the
experiment completed, and the window was explicitly released. Tyler accepted the
Escape-cancellation amendment. The final independent proof review reports only

   choosing an experiment. Review artifacts are separate, numbered rounds.

   Approval includes targeted bootstrap follow-up, scoped plugin installation,
   and at most one fresh Desktop execution-owner task if resumed discovery fails;

3. After approval, Terra 6.1 owns implementation in this task worktree. Its first
   job is the bounded feasibility gate, not an integration build. It verifies
   current state again and follows the single worker candidate in the spec,
   establishes genuine admission, native interaction and fresh-task repetition.
   Sol serializes runtime work and adjudicates scope. A runtime probe may use
   Luna as requested by repository instructions; Terra remains implementation owner.
4. A failed prerequisite or exhausted budget produces a scoped finding. Sol does
   not authorize speculative additional infrastructure without an amended spec.
5. After a passing gate, Sol identifies the proved route and presents any concrete
   integration contract amendment for Tyler's approval before product code changes.
   Then implement the minimum required maintained integration or operational
   configuration. The existing worker may need no code changes.
   Required focused tests belong beside changed code. No proof program is committed.
6. Sonnet independently validates actual implementation and live proof against
   the approved contract, using `/adversarial-review`. Runtime observations are
   serialized with Terra's work. Sol resolves material findings through
   `/consensus` with new numbered review files, preserving the reviewer session.
7. Report proved revision, claims met/unmet, original observation links,
   qualification limits, exact recipe and cleanup/ownership state. Checkpoint
   and push interesting work; no premature completion from workflow status.
