# TypeSafe Jev Readiness for Gimbal

This note outlines how Gimbal Go maintainers should responsibly adopt TypeSafe Jev. It records architectural decisions but does not guarantee that Jev improves Gimbal outcomes. Keep a clear distinction between officially documented API limits, locally proven smoke test results, and our unverified hypotheses about live supervision benefits.

## SDK Choice and Integration

For initial Go experiments, use the unofficial community client `github.com/kazz187/jev-sdk-go` v0.2.0. It is dependency-free, supports our Go 1.27.1 requirement, preserves caller-defined string types in `Choice` returns, and supports heterogeneous batch requests cleanly. 

While a live call on a synthetic failed-test snapshot proved basic authentication, request serialization, and response decoding against `jev-1.13.0` (returning probability `0.990`), **this only proves transport, not supervision quality**. 

**Integration rules:**
- Do not add an unused dependency to the root Gimbal module; isolate experiments.
- Keep `TYPESAFE_API_KEY` securely out of the repository.
- Pin both the SDK version and the `jev-1.13.0` model.
- If the SDK becomes a maintenance burden, fall back to a minimal standard-library `net/http` client rather than building custom Gimbal wrappers.
- Use TypeSafe's official agent skill for question design instead of Go-specific adapter prompts.

## Best First Use: Frequent Supervision Screening

Jev's primary hypothesized value is screening every completed, provider-exposed reasoning message to decide whether to trigger an existing generative supervisor. Gimbal's `WithSupervisor` currently runs on a three-minute timer. Each attached rule gets its own Jev request; review and steering have separate cooldowns. Jev cannot generate the steering text itself.

**Screening Design:**
- **State Snapshot:** Include the task constraint, recent meaningful transcript slices, and explicit Go facts (exit codes, test results). Do not ask Jev to count or perform arithmetic; use exact Go signals.
- **Bounded Questions:** Ask one rule-specific Choice question per request. Examples: Does the plan conflict with task constraints? Does the claim contradict observed test results? Is the agent repeating a failed approach?
- **Escalation Logic:** Jev outputs probability features, not ground-truth correctness. Treat its answers as advisory.

**Validation Path:**
1. **Offline Replay:** Test Jev against saved Gimbal turns with labeled intervention moments.
2. **Measurement:** Compare Jev's output against the current generative supervisor and exact Go signals. Measure false escalations, recall, latency, and cost. Tune thresholds on a training split and evaluate on held-out runs. Do not assume Jev is automatically calibrated for Gimbal.
3. **Live Shadow Mode:** Run Jev alongside the current supervisor without gating it.
4. **Active Triggering:** Only once offline and shadow performance prove safe, use Jev to actively trigger generative review.

## Other High-Value Uses

Beyond frequent screening, consider Jev for:
1. **Evidence Selection:** Deterministically retrieve candidate excerpts, then use Jev to rank relevance or flag contradictions before handing them to a generative researcher.
2. **Claim vs. Evidence Checks:** For proposed fixes, verify exact file paths and exit codes in Go, then ask Jev to judge if the cited source actually supports the claim. Uncertain cases escalate to the generative validator.
3. **Intent Routing:** Use bounded `Choice` primitives to route tasks to specific skills or model tiers. Always shadow-test dispatch decisions first.

## Limitations and Safety Boundaries

- **Capabilities:** Jev returns bounded judgments (`Noul`, `Choice`, `Score`). It cannot write prose or process media.
- **Economics:** Published limits (e.g., 64k total context, 32k max state, $0.042/Mtok for input) allow bounded loops. However, total system savings depend on snapshot sizes, polling frequency, and the rate of false escalations triggering expensive supervisor calls.
- **Model Jaggedness:** TypeSafe explicitly warns against asking Jev to count, compare dates, or parse adversarial text. Jev suffers from context rot on excessively long state payloads.
- **Data Privacy:** TypeSafe says customer requests are not used for training, while "Zero Data Retention" (ZDR) is an enterprise offering. Decide what proprietary data may leave Gimbal, minimize snapshots, and remove secrets before sending them. Never let a confident Jev answer override observed local evidence.
