# Jev Readiness for Gimble

**SDK Choice:** Use `github.com/kazz187/jev-sdk-go` v0.2.0. Local smoke tests proved basic API authentication, serialization, and decoding. Pin the SDK and `jev-1.13.0`. Use TypeSafe's official skill for question design.

**Supervision Screening:** Jev's best first use is deciding whether to call Gimble's generative supervisor. Try small snapshots frequently (perhaps every 15–30s when new evidence exists). Ask bounded semantic questions. Outputs are advisory features.

**Evidence Needed:** Supervision benefits are unverified. First, perform offline replays over saved Gimble turns. Compare exact Go signals, current supervisors, and Jev questions. Measure false escalations, latency, and cost before testing live shadow judgments.

**Other Promising Uses:**
1. **Evidence Selection:** Rank excerpt relevance for semantic indexes.
2. **Validation:** Judge if citations support a claimed fix after verifying Go facts.
3. **Intent Routing:** Suggest workflows using closed choices.

*Constraints:* Jev returns `Noul`, `Choice`, or `Score` judgments, not generated prose. Treat transcripts as untrusted data.
