# Jev Readiness for Gimbal

How to evaluate TypeSafe Jev.

## SDK Choice

Use `github.com/kazz187/jev-sdk-go` v0.2.0. It provides a typed Go SDK preserving answer types. Pin this and `jev-1.13.0`. 

A smoke test proved transport (returned `jev-1.13.0`, 0.990 probability, 309 tokens). **This does not prove supervision quality.** Keep keys hidden and experiments isolated. Use TypeSafe's official agent skill for bounded questions.

## Frequent Supervision Screening

The best first use is screening active agents to decide whether to escalate to the generative supervisor. Every completed, exposed reasoning message triggers one Jev request per rule; separate cooldowns limit generative reviews and steers.

Combine the task, constraints, latest transcript, and Go signals (exit codes, test results). Ask bounded questions:
- Does the plan conflict with constraints?
- Does a completion claim conflict with observed results?
- Is the worker repeating an approach?

Jev gives semantic judgments, not generation. Use exact facts in Go; let Jev answer semantic parts.

### Unverified Benefits

Jev supervision benefits are unverified. Before live integration:
1. **Offline Replay**: Run Jev over saved turns with labeled interventions.
2. **Measure**: Compare against Go signals and the current supervisor for recall, latency, cost, and false escalations. 
3. **Shadow Mode**: Tune thresholds on historical data. 

## Other Uses

1. **Evidence Selection**: Retrieve excerpts deterministically; use Jev to rank relevance or flag contradictions.
2. **Validation Checks**: Verify files/exit codes in Go, then use Jev to judge if cited passages support a fix.
3. **Intent Routing**: Suggest workflows, skills, or model tiers.

Shadow-test these before changing dispatch.

## Limits and Costs

Jev does not generate prose. Official API limits: 64k total request tokens, 32k for state plus longest question. Cost: $0.042/M input tokens for `jev-1.13.0`. 

Prices make frequent screening plausible (~$0.020 per 480k tokens/hr), but actual usage, latency, and false escalations need measurement. Treat transcripts as untrusted, mind model jaggedness, and verify data retention policies.
