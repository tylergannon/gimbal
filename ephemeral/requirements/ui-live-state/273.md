# #273: Live workspace shows Connecting / Disconnected 0 s while idle instead of a live-idle state

State at preparation: OPEN

On a live run with no events for a while, the topbar reads `Disconnected 0 s` or an interview stays `Connecting` for minutes even though the SSE stream is open (`web/src/lib/observation/index.ts` and the topbar's live badge). The design has three states: live, disconnected with a duration, and recorded. Idle-but-connected should read live.

Found by the build-frontend validator on the new run interface (PR #267, merged as a533c17). Small gap under the 90 to 95 percent rule; listed, not blocking.

No issue comments at preparation.
