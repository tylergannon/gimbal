# Use Gimbal route

Use this route as a programmer or agent calling an existing workflow in a
project. It covers the meaning of the work and its evidence as well as commands.

Use the vocabulary to understand the chosen workflow's contract. Do not require
a chapter, sprint ledger, promise badge, or formal review loop for every command.
The `df-*` documents teach methods; they are not evidence that corresponding
Gimbal built-ins exist. Start with actual installed help and consult
[authority and conflicts](../authority/index.md) when guidance differs.
