### Excerpt 3: Placement of Typed Go Form Client Generation

In order to support typed Go Form clients:
1. `internal/gen` needs to scan `kindForm` declarations and identify their input and output types.
2. Rather than emitting private client protocol logic in Gimbal, SKGO must emit typed client methods:
   `func (c *Client) <RemoteName>(ctx context.Context, in <InputType>) (<OutputType>, error)`
   or a package of client callers.
3. The client calls a shared SKGO transport function (in `skgo` or `skgo/client`) that:
   - Encodes `<InputType>` into `application/x-sveltekit-formdata` binary envelope using `formdata.Serialize` (or shared encoder).
   - Issues `POST` request over the configured `http.RoundTripper` / `*http.Client`.
   - Parses HTTP 200 JSON envelope:
     - If `type == "error"`: returns `*skgo.HTTPError{Status, Message}`.
     - If `type == "result"`: decodes `data` with devalue.
       - If `issues` present: returns `*skgo.Invalid{Issues: ...}`.
       - If `result` present: returns decoded typed `<OutputType>`.
   - Honors caller context cancellation: cancels network wait without issuing cancellation commands.
   - Refrains from automatic mutation retries.
