# Workflow role defaults

correction: Generated workflow role defaults are the intended configuration. Do not pass role-model flags by default or replace them because of generic cost guidance. An override requires an explicit user request, or an unavailable default and user approval for the replacement.

friction: The Gimbal user skill said to supply role models through generated flags, which encouraged restating and accidentally replacing correct workflow defaults. Generated help now labels configured role flags as advanced overrides, and the skill instructs callers to omit them.
