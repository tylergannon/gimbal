## Resume 2 (busy-thread gap)
decision: Codex RunTurn no longer errors when the thread's history shows an earlier inProgress turn. It interrupts it once, then rereads native status every busyPoll under the new prompt's own ctx and sends turn/start only after no turn is in progress. Cancelling that ctx (Stop/Finish) returns plain ctx.Err(), no DeliveryUncertain, nothing started; Interactive marks the input unprocessed and the conversation stays open (new Interactive test). Steer during the wait finds no active turn and stays queued. Late notifications of the old turn are dropped by readTurn's turn-id match (fixture sends them).
decision: a native turn that completed (readTurn err==nil) is returned even if ctx was cancelled meanwhile; fixture cancels from the step.ended event of the terminal notification (conn.next checks ctx first, so this is deterministic). Reverting the guard fails the test.
limitation: wait is unbounded except by the prompt's ctx; if Codex never settles the old turn, the prompt stays Running until the human Stops it. busyPoll is a package var (tests shorten it).
