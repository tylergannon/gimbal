# Local run boundary

decision: The 2026-10-10 recovery handoff is authorized by Tyler's implementation request. Its 2,000 gross handwritten addition tripwire and early working checkpoint govern delivery; old proposals add no scope.

friction: Stock generation recovery tests mutated the checkout, causing other packages to see missing adapters during parallel tests. The test now works in its own source copy. Child re-exec also needs the existing CLI TestMain to dispatch run-process before testing flags; otherwise launching a workflow recursively starts the test suite.

review: A workflow panic could bypass the runner's retained cleanup wait. Recovery now surrounds ordinary gimbal.Run, and a package test verifies that cleanup remains reachable and a retry releases the child.

decision: External observation reads no longer repair tables or snapshots. Tests must verify the read view and absence of writes. A run page reads the graph saved with that run; browser fixtures therefore need a saved graph, and rebuilding a server cannot repair an older missing graph.

review: A stopped writer can leave a partial durable transaction, including valid JSON without its newline. Both loading and following now consume only newline-terminated transactions; stopped-writer settlement truncates to the last complete transaction before appending failure. Both tail shapes are covered beside the observation code.

friction: The new adapter template initially grouped standard-library and module imports together. The commit formatter changed generated bytes, which the recovery test correctly rejected. The template now emits the same import groups as goimports.
