# Environment UI decisions

- Session setup keeps branch/base/isolation/model choices per environment inside the retained NewSession component. Selecting an environment only reads setup; the first-message form remains the admission boundary.
- Machines is a web pane in native Settings alongside Recording. Same-origin native handlers open Settings, SSH Terminal connections and the owning session in the main workspace; address and route entries give explicit terminal instructions.
- Configuration editing captures its original byte revision. A live refresh cannot advance that revision under unsaved text. Explicit reload uses a fresh remote form instance, because SvelteKit caches keyed form fields across a same-key remount.
- Opaque configuration fields stay in the Go store. The frontend parses only the display fields needed for connection details, while the configuration editor edits the actual active file.
- Machine removal names retained sessions and waits for their explicitly selected, confirmed cleanup. A rejected cleanup leaves the removal disabled and its error visible.
- Generator friction: commands require RequestEvent even when they have no route identity; duplicate Harness names require consumers to use Setup's indexed harness type rather than an unstable generated collision alias.
- Native validation exposed an integration boundary missed by component mocks: instance project routing rejected the new global environment remotes from Settings because their module was absent from the shared-remotes list. The same URLs worked with an admitted project Referer. Global machine operations and the explicit-project cleanup command now pass that gate; project-sensitive controls keep their existing gate. The HTTP regression covers both Settings routes and a native caller without Referer.
- Live-query errors may be serialized App.Error objects rather than Error instances. Render their message explicitly instead of coercing the object to text.
- Directory admission must resolve a prospective machine from Service's independently validated cache, not decode the raw file again in a remote. Whole-document typed decoding lets one malformed sibling disable otherwise usable machines. Inspection, listing and explicit clone now share the service resolver; configuration bytes and opaque fields remain untouched.
- Native Add Environment is an action, not merely a destination URL: repeating it for the same project must refresh the action route after its previous sheet closes. Its presentation revision advances only for explicit Add requests; ordinary Machines/Recording presentation retains the existing view.
- Native validation isolated connection pressure from execution: the same application and catalog navigated and cancelled promptly with one retained chat, then stalled after opening saved chats without starting agent work. Retained panes each held a live query, including idle chats. This Kit version releases live-query proxy references through FinalizationRegistry, so unmounting or dropping a conditional proxy does not deterministically close its network connection.
- Conversation panes now use their existing workspace inventory instead of opening one stream each; accepted-but-not-yet-delivered prompts keep the inventory updating while the conversation still says idle. Run panes explicitly close their EventSource when inactive and resume from the retained observation cursor. Drafts, map selection and other retained DOM state stay mounted.
- Retained transcripts and NewSession inventory use typed finite queries, refreshed only while visible and again on revisit. The recording receipt bridge receives a final saved snapshot and then its server producer ends; terminal display receipts remain available only for the matching recording identity. Main-workspace stream use no longer grows with its retained chat/run/recording tabs; this does not establish a universal bound across arbitrarily many document windows.
